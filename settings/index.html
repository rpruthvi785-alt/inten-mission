Deploy Backend (Railway — Free Tier)

  1. 1Go to railway.app and create a free account.
  2. 2Click "New Project" → "Deploy from GitHub repo" → select your repo.
  3. 3Set the Root Directory to: backend
  4. 4Add environment variables from backend/.env.example
  5. 5Railway will auto-detect Node.js and deploy using railway.toml
  6. 6Copy your Railway URL (e.g. https://inten-match.railway.app)
  7. 7Paste it above → Save URL → Test Connection
  8. 8Add it to GitHub Actions secret NEXT_PUBLIC_API_URL for future builds
Open Railway.app

Bake Backend URL into GitHub Pages Build

Once you have a permanent backend URL, add it as a GitHub Actions secret so it gets baked into the static frontend bundle — no manual configuration needed on any device.

Steps:

1. GitHub repo → Settings → Secrets and variables → Actions

2. New repository secret: NEXT_PUBLIC_API_URL

3. Value: https://your-backend.railway.app

In .github/workflows/deploy.yml:

NEXT_PUBLIC_API_URL: ${{ secrets.NEXT_PUBLIC_API_URL }}
